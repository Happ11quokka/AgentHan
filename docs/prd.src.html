AgentHan · 외국인 사장님의 네이버 비서

비서가 하는 일을 두 가지로 봤다. 사장님의 가게 일을 돕는 것과 손님을 응대하는 것이다. 현장 인터뷰에서 외국인 사장님들은 네이버 기능이 있어도 몰라서 못 쓰고 있었고, 한국어가 되는 사람이 없을 때는 전화 주문을 받지 못했다. 그래서 가게 일은 사장님이 한마디 하면 스마트플레이스 기능을 찾아 입력까지 해 주고, 리뷰 정리 같은 반복 일은 비서가 루틴으로 제안한다. 손님 응대는 한국인 손님의 전화 주문을 AI가 한국어로 받아 사장님 언어로 넘긴다.

정한 것과 남은 것

[D1]데모 저장소 · 결정 (11/21)

11/20에 서버 안 Docker pgvector/pgvector로 먼저 붙였고, 11/21에 운영 DB를 NCP Cloud DB for PostgreSQL agenthan-db(고가용성: Primary + Secondary, 자동 Failover, 매일 백업 7일)로 옮겼다. pgvector는 콘솔 Extension 관리로 설치했다.

별칭·규칙·BM25는 Python 그대로, 벡터만 pgvector(HNSW, cosine). DB가 없거나 죽으면 경고만 남기고 JSON 파일로 동작한다. 서버 안 db 컨테이너는 발표 뒤까지 예비로 둔다. 자세한 것은 docs/db.md.

[D2]계약 함수 동기/비동기 · 결정

계약은 보통 함수(def)로 둔다. async 코드(전화 세션, FastAPI 핸들러)에서 부를 때만 별도 스레드로 돌린다. 전화의 DB 기록·후기 검색도 별도 스레드라 실패해도 통화는 이어진다.
